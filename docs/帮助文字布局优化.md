# 帮助文字布局优化说明

## 问题描述

AI模型配置界面中，"获取 API Key" 帮助文字区域存在宽度被挤压的问题：

**症状**:
- 帮助文字区域只占用一半可用空间
- 文本不必要地换行
- 布局看起来不平衡

**原因分析**:
```python
# 问题代码结构
register_content (水平布局)
├── info_icon (side=tk.LEFT)          # 图标
├── text_container (side=tk.LEFT)     # 文字容器 - 被挤压
└── link_frame (side=tk.RIGHT)        # 注册按钮 - 抢占空间
```

使用 `side=tk.LEFT` 和 `side=tk.RIGHT` 的混合布局时，右侧的注册按钮会优先分配空间，导致中间的文字容器被挤压。

## 解决方案

### 改为垂直布局

将水平三栏布局改为垂直布局，确保文字有足够宽度：

```python
register_content (垂直布局)
├── title_row (水平布局)
│   ├── info_icon (side=tk.LEFT)
│   └── title_label "获取 API Key" (side=tk.LEFT)
├── help_text_lines (垂直堆叠)
│   ├── "1. 访问 ..."
│   ├── "2. 注册并登录账号"
│   ├── "3. 创建 API Key"
│   └── "4. 将 API Key 复制到上方输入框中"
└── button_row
    └── register_btn "前往注册 →"
```

### 代码实现

```python
# 注册说明 - 优化布局
register_frame = tk.Frame(content_frame, bg="#FEF3C7", relief="flat", bd=0)
register_frame.pack(fill=tk.X, pady=(0, 10))

register_content = tk.Frame(register_frame, bg="#FEF3C7")
register_content.pack(fill=tk.X, padx=12, pady=10)

# 标题行：图标 + 标题
title_row = tk.Frame(register_content, bg="#FEF3C7")
title_row.pack(fill=tk.X, pady=(0, 5))

info_icon = tk.Label(title_row, text="ℹ️",
                     font=("Apple Color Emoji", 14),
                     bg="#FEF3C7")
info_icon.pack(side=tk.LEFT, padx=(0, 8))

title_label = tk.Label(title_row, text="获取 API Key",
                      font=("SF Pro Display", 11, "bold"),
                      fg="#92400E", bg="#FEF3C7",
                      anchor="w")
title_label.pack(side=tk.LEFT)

# 步骤说明
help_text_lines = [
    f"1. 访问 {config.get('register_url', '').split('//')[-1].split('/')[0]}",
    "2. 注册并登录账号",
    "3. 创建 API Key",
    "4. 将 API Key 复制到上方输入框中"
]

for line in help_text_lines:
    line_label = tk.Label(register_content, text=line,
                         font=("SF Pro Display", 11, "normal"),
                         fg="#92400E", bg="#FEF3C7",
                         anchor="w")
    line_label.pack(anchor="w", pady=1, padx=(22, 0))  # 左侧缩进22px对齐

# 注册链接按钮
def open_register_url():
    webbrowser.open(config.get('register_url', ''))

button_row = tk.Frame(register_content, bg="#FEF3C7")
button_row.pack(fill=tk.X, pady=(8, 0), padx=(22, 0))

register_btn = tk.Label(button_row, text="前往注册 →",
                        font=("SF Pro Display", 11, "bold"),
                        fg="#4F46E5", bg="#FEF3C7",
                        cursor="hand2")
register_btn.pack(side=tk.LEFT)
register_btn.bind("<Button-1>", lambda e: open_register_url())
```

## 布局优化细节

### 1. 标题行独立

```
ℹ️ 获取 API Key
```
- 图标和标题在同一行
- 使用加粗字体突出标题
- 与步骤说明分开，层次更清晰

### 2. 步骤缩进对齐

```
    1. 访问 help.aliyun.com
    2. 注册并登录账号
    3. 创建 API Key
    4. 将 API Key 复制到上方输入框中
```
- 左侧缩进 22px，与图标+标题对齐
- 每个步骤独立一行
- 序号清晰易读

### 3. 按钮独立行

```
    前往注册 →
```
- 与步骤说明保持相同缩进
- 上方留出 8px 间距
- 蓝色文字突出可点击性

## 技术亮点

1. **垂直优先布局**: 避免水平方向空间竞争
2. **语义化层次**: 标题、步骤、按钮分层清晰
3. **对齐系统**: 使用固定缩进值（22px）保持视觉一致性
4. **留白控制**: 合理的 `pady` 间距营造呼吸感

## 兼容性

- ✅ 适应不同对话框宽度
- ✅ macOS 和 Windows 平台一致
- ✅ 支持中英文混排
- ✅ 长URL自动折行
