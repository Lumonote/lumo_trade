## 🧠 智能分析算法

### 信息可信度评估算法

#### 多维度评分体系
```
总可信度 = 信息源权威性(25%) + 历史准确性(30%) + 信息具体性(20%) + 交叉验证(15%) + 时间逻辑(10%)
```

- **信息源权威性评估**:
  - 内部员工消息: 90分
  - 行业专家分析: 80分  
  - 资深投资者: 70分
  - 普通散户传言: 40分

- **历史准确性评估**:
  - 基于用户历史发言的准确率统计
  - 近期准确率权重更高
  - 连续准确预测给予加分

- **信息具体性评估**:
  - 包含具体时间、金额、人物: +20分
  - 描述详细过程和背景: +15分
  - 仅为模糊传言: -10分

#### 交叉验证算法
- **多源印证**: 同一信息出现在3个以上独立渠道，可信度+30%
- **时间一致性**: 不同来源信息时间逻辑吻合，可信度+20%
- **逻辑自洽性**: 信息内容符合商业逻辑，可信度+15%

### 提前捕捉时间窗口预测
