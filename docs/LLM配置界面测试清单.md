# LLM配置界面测试清单

## 测试前准备

1. 确保已通过"安装依赖"按钮安装了pandas等依赖
2. 准备好通义千问或DeepSeek的API Key（可选，用于完整测试）

## 功能测试

### ✅ 测试1: 界面打开测试

**操作步骤**:
1. 启动Kronos应用（.app或GUI）
2. 点击"AI模型配置"按钮

**预期结果**:
- [ ] 配置对话框成功打开，无pandas错误
- [ ] 界面显示完整，无布局错乱
- [ ] 两个LLM服务区块（通义千问、DeepSeek）正常显示

### ✅ 测试2: 帮助文字布局测试

**操作步骤**:
1. 打开AI模型配置对话框
2. 查看"获取 API Key"帮助文字区域

**预期结果**:
- [ ] 帮助文字显示为4行独立文本
- [ ] 每行对齐正确，无重叠
- [ ] ℹ️ 图标显示在左侧
- [ ] "前往注册 →"按钮显示在右侧
- [ ] 黄色背景区域布局正常

**帮助文字内容应为**:
```
ℹ️  获取 API Key：1. 访问[域名]         前往注册 →
   2. 注册并登录账号
   3. 创建API Key
   4. 将API Key复制到配置中
```

### ✅ 测试3: API地址配置字段测试

**操作步骤**:
1. 打开AI模型配置对话框
2. 定位"API 地址（可选，留空使用默认）"字段

**预期结果**:
- [ ] 标签文字清晰可见
- [ ] 输入框正常显示
- [ ] 默认URL提示显示在输入框下方
- [ ] 通义千问默认提示: `默认: https://dashscope.aliyuncs.com/api/v1`
- [ ] DeepSeek默认提示: `默认: https://api.deepseek.com`

### ✅ 测试4: 配置保存测试（无API Key）

**操作步骤**:
1. 打开AI模型配置对话框
2. 启用通义千问或DeepSeek
3. 不填写API Key
4. 点击"保存配置"

**预期结果**:
- [ ] 配置成功保存
- [ ] 显示"✅ 配置保存成功！"提示
- [ ] 对话框关闭
- [ ] 重新打开配置对话框，启用状态保持

### ✅ 测试5: 自定义API地址保存测试

**操作步骤**:
1. 打开AI模型配置对话框
2. 在"API 地址"字段输入自定义URL: `https://custom-api.example.com`
3. 点击"保存配置"
4. 重新打开配置对话框

**预期结果**:
- [ ] 配置成功保存
- [ ] 重新打开后，自定义URL显示在输入框中
- [ ] 配置文件中base_url字段更新为自定义URL

### ✅ 测试6: 测试连接功能（无API Key）

**操作步骤**:
1. 打开AI模型配置对话框
2. 不填写API Key
3. 点击"测试连接"按钮

**预期结果**:
- [ ] 显示警告对话框："请先填写 API Key"
- [ ] 测试按钮状态不变

### ✅ 测试7: 测试连接功能（有API Key）

**操作步骤**:
1. 打开AI模型配置对话框
2. 填写有效的API Key
3. 点击"测试连接"按钮

**预期结果**:
- [ ] 按钮文字变为"测试中..."
- [ ] 按钮禁用状态
- [ ] 等待2-5秒后，显示测试结果
- [ ] 按钮恢复为"测试连接"
- [ ] 显示成功或失败对话框（取决于API Key有效性）

**成功提示**: `✅ [通义千问/DeepSeek] 连接测试成功！`

**失败提示**: `❌ 连接测试失败\n\n[错误信息]`

### ✅ 测试8: 完整配置流程测试

**操作步骤**:
1. 打开AI模型配置对话框
2. 启用通义千问
3. 填写API Key: `sk-test123456`
4. 填写自定义API地址: `https://proxy.example.com/qwen`
5. 点击"保存配置"
6. 关闭应用并重新启动
7. 重新打开AI模型配置对话框

**预期结果**:
- [ ] 通义千问启用状态保持
- [ ] API Key显示为星号遮蔽
- [ ] 自定义API地址正确显示
- [ ] 配置文件正确保存所有字段

### ✅ 测试9: 配置文件验证

**操作步骤**:
1. 执行测试8的完整配置
2. 打开配置文件: `config/llm_config.json`
3. 检查文件内容

**预期配置文件格式**:
```json
{
  "qwen": {
    "enabled": true,
    "api_key": "sk-test123456",
    "model": "qwen3-max",
    "base_url": "https://proxy.example.com/qwen",
    "register_url": "https://help.aliyun.com/zh/dashscope/developer-reference/activate-dashscope-and-create-an-api-key",
    "description": "阿里云通义千问大模型"
  },
  "deepseek": {
    "enabled": false,
    "api_key": "",
    "model": "deepseek-chat",
    "base_url": "https://api.deepseek.com",
    "register_url": "https://platform.deepseek.com/api_keys",
    "description": "DeepSeek 大模型"
  }
}
```
