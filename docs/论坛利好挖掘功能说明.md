# 关键词驱动论坛利好挖掘功能说明

## 功能概述

Kronos 项目的 quick_start 选项 10 现在支持三种挖掘模式：

### 1. 关键词优先模式 🚀🚀(强烈推荐)
- **核心优势**: 根据利好关键词反向搜索股票，更精准、更全面
- **搜索策略**: 先搜索重大利好关键词，再从讨论中提取股票代码
- **覆盖范围**: 不受热门股票列表限制，能发现小众机会

### 2. 论坛情绪模式 🚀
- **基础模式**: 从热门股票中分析论坛情绪变化
- **数据来源**: 东方财富股吧、同花顺、雪球等论坛
- **分析维度**: 情绪变化、讨论热度、关键词频率

### 3. 新闻资讯模式
- **传统模式**: 从财经新闻、公告资讯中挖掘
- **时效性**: 相对滞后，适用于验证已公布消息

## 使用方法

### 命令行方式

## 关键词优先模式详解

### 核心理念：反向挖掘
传统模式：`股票列表 → 论坛分析 → 发现利好`
关键词模式：`利好关键词 → 论坛搜索 → 提取股票`

### 搜索策略

#### 五级优先级关键词体系
1. **Tier 1 - 最高优先级（权重10）**
   - 重组并购类：重大重组、资产重组、并购、收购、借壳上市
   - 触发条件：帖子中出现相关关键词

2. **Tier 2 - 高优先级（权重9）**
   - 重大合同订单：百亿订单、重大合同、中标公告
   - 市场影响：直接影响业绩的重大业务

3. **Tier 3 - 中高优先级（权重8）**
   - 政策利好：政策扶持、国家支持、财政补贴、纳入名单
   - 长期价值：政策红利释放

4. **Tier 4 - 中优先级（权重7）**
   - 技术突破：技术突破、专利授权、核心技术、研发成功
   - 竞争优势：技术护城河构建

5. **Tier 5 - 基础优先级（权重6）**
   - 业绩爆发：业绩大增、利润暴增、超预期、业绩预增
   - 财务改善：盈利能力提升

### 股票代码智能提取

#### 多模式识别算法
- **标准格式**: `000001`, `600000`, `300001`
- **交易所格式**: `000001.SZ`, `600000.SH`
- **前缀格式**: `SZ000001`, `SH600000`
- **板块识别**: 自动识别主板、中小板、创业板、科创板

#### 提取精度优化
- 上下文语义分析
- 无关数字过滤
- 重复提取去重
- 有效性验证

### 多维度置信度评分 (0-100分)

#### 评分算法
```
总分 = 基础分(30) + 关键词权重分(40) + 多样性分(15) + 数据源分(10) + 时效性分(5)
```

#### 具体计算
1. **基础分** (最高30分): `min(提及次数 × 10, 30)`
2. **关键词权重分** (最高40分): `min(平均关键词权重 × 4, 40)`
3. **关键词多样性分** (最高15分): `min(关键词类型数 × 5, 15)`
4. **数据源多样性分** (最高10分): `min(数据源数量 × 5, 10)`
5. **时效性加分** (最高5分): 24小时内+5分，48小时内+3分

#### 等级划分
- **S级** (85+分): 极高置信度，重点关注 🔥🔥🔥
- **A+级** (75-85分): 高置信度，优先考虑 🔥🔥
- **A级** (65-75分): 较高置信度，值得关注 🔥
- **B级** (50-65分): 中等置信度，谨慎参考
- **C级** (50分以下): 低置信度，仅供参考

## 风险提示与最佳实践

### ⚠️ 重要提示
1. **高置信度 ≠ 100%准确**: 任何量化分析都存在误判可能
2. **论坛消息 ≠ 官方公告**: 需要后续验证
3. **投资有风险**: 本工具仅供参考，不构成投资建议

### 🎯 最佳实践
1. **优先使用关键词模式**: 发现面更广、精度更高
2. **重点关注S级机会**: 集中精力分析最有价值的标的
3. **多维度验证**: 结合技术面、基本面、消息面分析
4. **控制仓位**: 单只股票不超过总资金10%
5. **及时止损**: 设置合理止损位，控制下行风险

### 📊 效果评估
- **准确率统计**: 定期回测预测准确率
- **收益跟踪**: 记录基于推荐的投资表现  
- **策略优化**: 根据效果调整关键词权重
