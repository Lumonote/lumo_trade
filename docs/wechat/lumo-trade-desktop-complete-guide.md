# 把行情、资金、量化、风控和复盘装进一台桌面工作站：Lumo Trade 完整功能解析

> 本文以 Lumo Trade 桌面包 v1.1.6 为基准，逐一拆解 15 个桌面页面、21 个页签的个股工作台，以及贯穿全局的 10 项桌面能力。

---

很多投资工具只解决一个局部问题：行情软件负责看盘，选股器负责筛选，量化脚本负责跑信号，新闻终端负责追热点，表格负责记持仓——最后还得靠人肉把这些信息拼成结论。

**Lumo Trade 想解决的是另一类问题：**

能不能把"观察市场 → 发现机会 → 研究个股 → 识别风险 → 模拟执行 → 跟踪复盘"放在同一套桌面工作流里，并且让所有数据、任务和报告尽量留在本机？

这就是 Lumo Trade 的出发点。它不是单纯的 K 线预测器，也不是只打几个分数的选股页面，而是一套面向 A 股研究场景的**本地智能投研控制台**。

先说一组基础数字，帮你建立一个量感：

> 📊 **桌面页面** 15 个 · **个股分析页签** 21 个 · **后端 API 路由** 117 个 · **量化模型** 30 个 · **自动化测试** 109 个文件

下面按"投研链路 → 页面职责 → 跨页面能力 → 技术架构 → 实际工作流 → 系统边界"六个部分展开。

*Lumo Trade 将市场观察、机会发现、个股分析、任务和报告统一到桌面工作台中。*

## 一、它解决的不是"预测一次"，而是一条完整投研链路

从用户视角看，Lumo Trade 的核心不是某单个页面有多强，而是六个环节首尾衔接。

```
市场全景  →  候选池  →  分层评分  →  个股深研  →  风控决策  →  沉淀复盘
  ①             ②           ③            ④            ⑤             ⑥
```

### ① 建立市场全景

打开应用后，先通过**总览、大盘云图、资金榜单、量化雷达、股指期货和实时资讯**了解当日市场状态：

- 指数怎么走？
- 上涨和下跌家数如何分布？
- 资金在流向哪些行业？
- 热点是扩散还是收缩？
- 期指的升贴水和多空席位有没有异常？

### ② 形成候选股票池

候选来源不用手动翻——系统提供多条汇聚路径：

- 多源机会挖掘引擎
- 热门板块和东方财富热榜
- 主力资金流向 Top N
- **条件选股器**：行情 × 资金 × 盘口异动 × 龙虎榜 × 技术形态 × 量化模型信号，八个维度取 AND 交集

### ③ 对候选进行分层评分

机会挖掘引擎采集行情、资金、基本面、新闻、情绪和板块信息，调用评分规则和 30 个量化模型，生成综合评分、评级、加减分项和风险提示。不是给个分数就完——每一分都有加减分项可追溯。

### ④ 进入个股深度研究

任何股票都可以从榜单、画布、热力图、自选、模拟盘或搜索框，一键打开统一的**股票工作台**——不是一张简单详情卡，而是 **21 个分析页签**的个股研究套件。

### ⑤ 形成行动和风控

**风险·机遇页面**把机会分、市场风险、板块拥挤、个股风险和持仓风险放在同一张决策大屏里。"机会分高 ≠ 风险低"——这是设计这个页面的底层逻辑。

**模拟盘**则用于验证买入方式、持有周期和胜率，给想法一个低成本的测试场。

### ⑥ 沉淀为任务、报告和历史数据

耗时分析在后台运行，任务队列持续显示状态和日志。结果进入本地报告库、机会历史、股票池、板块池、形态回测和 SQLite 数据库——下一次研究时可以直接复用，不需要从头来过。

## 二、15 个桌面页面逐一拆解

### 1. 总览 · 打开应用后的第一个画面

总览负责回答三个问题：**市场现在怎样、系统是否可用、下一步从哪里开始**。

核心区域：
- 上证指数、监控股票数量、最新机会数量三项核心指标
- 个股快搜，按代码或名称直达个股分析
- 实时异动列表
- 新浪 7×24、东方财富 7×24、同花顺电报等资讯入口
- 东方财富热榜与板块动量
- 系统状态提示（市场、任务、配置、数据源）
- 后台配置和首页快捷入口

总览不追求把所有数据堆在首屏——它是进入各专业工作区的总闸。

![配图 02：总览页市场指标与热榜](images/02-overview-market-panels.png)
*个股快搜、核心指标、实时异动和东方财富热榜，构成总览的核心信息层。*

### 2. 大盘云图 · 把全 A 市场压缩成一张热力图

大盘云图是桌面端的市场空间视图：全市场股票按行业聚合，**矩形面积代表成交额，红绿颜色代表涨跌**。

能力清单：
- 覆盖上证指数、深证成指、创业板指、中证全指、上证 50、沪深 300、中证 500 等多指数
- 全部 / 上涨 / 平盘 / 下跌四态过滤
- 实时行情 + 指定交易日历史回溯
- TuShare → 东方财富 → 新浪 → 本地热门快照，四级数据源自动降级
- 辅助榜单：主力热股、涨幅榜、盘中异动、热门板块
- 点击板块 → 返回成分股，点击股票 → 打开个股工作台
- 全屏显示 + 定时刷新

这张图的用法很直接：**一眼判断市场热度是集中在少数几个行业，还是出现了显著的结构性分化**。

![配图 03：大盘云图全市场热力图](images/03-market-cloud.png)
*矩形面积 = 成交额，颜色 = 涨跌。全屏模式下可以快速感知市场温度分布。*

### 3. 风险·机遇 · 决策统筹层

这是整套系统的决策中枢——它不重新发明评分，而是**消费**机会挖掘、资金榜单、市场环境、自选和模拟持仓的已有结果，再叠加四层风险：

| 风险层级 | 关注点 |
| --- | --- |
| 市场系统性风险 | 指数趋势、波动率、流动性 |
| 板块拥挤风险 | 行业资金集中度、热度偏离 |
| 个股自身风险 | 追高、筹码、基本面异变 |
| 持仓组合风险 | 模拟持仓的集中度和相关度 |

核心区域：
- 市场风险、机会、情绪三项综合指数
- 资金、涨跌家数、成交额等原始状态指标
- **风险与机会撮合矩阵**——横轴是机会分，纵轴是风险分，四象限一目了然
- 行业热力和板块拥挤度
- 资金主线榜、机会榜、持仓与自选风险榜
- 当日热点、事件和复盘信息

> ⚠️ 风险·机遇页面如出现算法标签，不应让具体股票名称、代码或个人持仓与指令化标签同屏展示。

![配图 04：风险·机遇统筹大屏](images/04-risk-opportunity-command-center.png)
*机会分和风险分放在同一坐标系中——避免"只看高分、不看风险"的认知偏差。*

### 4. 资金榜单 · 不止看一日净流入

资金榜单包含三个工作模式：**主力净流入榜、龙虎榜、量化交易分析**。

**主力净流入 & 龙虎榜：**
- 单日 / 多日聚合，支持指定日期范围和聚合天数
- 5 日、30 日资金窗口，观察中期资金行为
- "无量化"过滤，剔除量化参与明显的股票
- 多选股票后一键调用机会挖掘分析
- 从榜单行直接打开个股、加自选或查看 K 线

**量化交易分析区：**
- 量化温度计——感知量化资金整体活跃度
- 量化活跃板块 & 活跃股票榜
- 收割预警——"只看砸盘"模式
- 20 日 / 40 日 / 60 日吸筹埋伏榜
- 个股量化行为深评
- 五类量化机制与防御知识卡

"吸筹"使用公开数据代理指标，关注资金持续流入但价格仍横盘的股票——系统明确标注这是疑似信号，不包装成确定性结论。

![配图 05：资金榜单与量化雷达](images/05-capital-and-quant-radar.png)
*上半部分：主力净流入榜；下半部分：量化温度计、活跃股和吸筹埋伏榜。支持多日聚合与交叉观察。*

### 5. 股指期货 · 观察现货背后的多空力量

覆盖中金所四大股指期货：IF（沪深 300）、IH（上证 50）、IC（中证 500）、IM（中证 1000）。

页面同时展示：
- 期货实时行情 + 现货指数 + 基差与贴水率
- 中金所前 20 席位：多单榜、空单榜、会员净持仓榜、成交量榜
- 多空持仓趋势图（近 10 日）

信号规则保持**透明**：
- 🔴 多增空减 → 偏多
- 🟢 空增多减 → 偏空
- 🟡 双增 → 分歧放大
- ⚪ 双减 → 资金离场

页面不把席位变化转成无法解释的黑盒分数。当日数据未发布时，自动回退到最近可用交易日并明确标注回退日期。

![配图 06：股指期货行情与前 20 席位](images/06-index-futures.png)
*期指行情、基差、多空摘要、会员净持仓榜和趋势图放在同一视图中，信息不分散。*

### 6. 条件选股 · 八维 AND 组合，结果可解释

条件选股把桌面应用已沉淀的数据能力组合成交叉筛选器。**留空的条件不参与筛选，填写了的条件之间取 AND 交集**。

八个筛选维度：

| 维度 | 可选条件 |
| --- | --- |
| 📈 行情快照 | 涨跌幅、价格、换手率、主板/创业板/科创板/北交所、排除 ST、排除涨停 |
| 💰 主力资金 | 当日主力净流入、净流入率、连续净流入天数 |
| ⚡ 盘口异动 | 量化活跃度、异动笔数、拉抬、砸盘预警 |
| 🎯 主力吸筹 | 20/40/60 日窗口、吸筹判定、埋伏评分 |
| 🐉 龙虎榜 | 最近 1/3/5/10 日上榜、累计净买入、量化席位 |
| 🏆 机会评分 | 最新机会挖掘综合评分 |
| 📐 技术形态 | 站上 MA20、MA5>MA10>MA20、20 日新高、MACD/KDJ 金叉、RSI 区间、量比 |
| 🤖 量化模型 | 30 个模型按最新 K 线的买入票数和卖出票数 |

命中结果支持按主力净流入、涨跌幅、量化活跃度、吸筹评分、机会评分、龙虎榜净买、换手率和量化买入票数排序。**每一个命中股票都可以一键进入个股工作台**——筛选不是为了筛选，是为了研究。

![配图 07：条件选股](images/07-stock-screener.png)
*八个维度可任意组合，所有留空条件不参与筛选。命中结果直接跳转个股工作台。*

### 7. 分析工作台 · 重型任务的发起与查看中枢

分析工作台是机会挖掘、批量分析和历史复盘的主操作区。

**任务发起：**
- 机会挖掘：候选数量、并发数、候选来源（多源综合 / 热门板块 / 热度候选 / 东方财富资金）、指定股票池
- 批量分析：一组股票代码 + 策略（balanced / strict / loose）+ 并发数

**结果查看：**
- 最新投资机会列表 + K 线预览 + 大图 K 线
- 量化模型摘要
- 批量分析结果 + 板块热点 + 涨幅与涨停榜 + 个股热度榜
- 金十快讯 + 最近任务 + 实时日志
- 历史挖掘、历史股票分析、股票池、板块池、历史热门板块

#### 投资机会画布

画布不是列表换了个皮肤，而是用来理解**"报告、板块、股票、分析内容"之间关系**的交互视图。

七种组织方式：
- **层级**：报告 → 板块 → 股票 → 分析内容
- **排名**：全部股票按综合评分排序
- **板块**：按板块聚合股票
- **标签**：按概念、板块等业务标签组织
- **热门**：前十大热门板块的全量关系
- **资金**：按主力净流入维度聚合
- **龙虎榜**：热门板块 × 龙虎榜命中的交叉关系

支持缩放、平移、重置、全屏、切换历史快照，以及将热门板块快照导出为 Excel。点击股票节点 → 加载 K 线和个股分析，画布和研究动作形成闭环。

*机会挖掘表单、投资机会列表、K 线、量化摘要和任务日志同屏呈现。*

![配图 09：投资机会关系画布](images/09-opportunity-canvas.png)

### 8. 挖掘引擎 · 把后台黑盒变成实时直播

机会挖掘往往需要较长时间——如果界面只有一个旋转图标，用户无法判断是"正在计算"、"在等数据"还是"已经卡住"。

挖掘引擎把运行过程拆成**可见阶段**：
- 候选收集 → 数据准备 → 多智能体并行分析 → 评分排序 → 报告生成 → 结果入库

页面提供：
- 总体进度环 + 预计剩余时间
- 阶段轨道（当前在哪个阶段、哪些已完成）
- 并行工作单元状态（每只股票的分析进度独立展示）
- 实时日志 + 成功/跳过/失败计数
- 结果直达入口

你可以从这里手动启动新任务，也可以**自动接管已经在后台运行的机会挖掘任务**——不丢失进度。

![配图 10：机会挖掘实时直播](images/10-discovery-live.png)
*耗时挖掘被拆成阶段、进度、并发工作单元和实时日志，不再是一个黑盒。*

#### 多空评审团

评审团按**价值、成长、宏观、技术、中国价投、游资和量化**七个流派组织，包含约 60 个规则化研究角色。每个流派使用对应的分析规则——不同流派对同一只股票的结论可能截然相反，这本身就是有价值的信息。

部分角色使用专门规则，部分使用流派默认规则。这些角色用于组织分析视角，不代表相关人物本人参与、授权或背书。AI 覆盖层可以在规则结论之上生成更完整的文字评审，但**规则基础始终保留**——大模型不可用时，评审团页面不会空白。

#### AI 解读

AI 解读使用用户在后台配置中启用的模型。当前支持 OpenAI 兼容接口和 DashScope 风格接口，可覆盖通义千问、DeepSeek、MiniMax、Kimi、GLM 等。**API Key 由用户自己配置**，桌面应用不应在截图或发布内容中暴露密钥。

### 9. 形态搜股 · 用一条曲线寻找相似股票

两种输入方式：

**🎨 手绘形态**：在画布上自由绘制期望的价格路径，命名、添加标签、保存或导出为 PNG/JSON，再检索全市场相似股票。

**📊 个股形态**：输入股票代码，载入该股最近一段时间的标准化价格曲线，以它为模板检索相似股票。

系统使用**本地形态指纹库**完成相似度检索，返回最相似股票列表和曲线叠加对比。首次使用或数据过旧时可以一键刷新指纹库。

匹配完成后，还可以对相似股票 Top 20 进行**近一年回测**：统计形态出现后 5 日、10 日、20 日的胜率和平均涨幅——用历史数据检验这个形态到底有没有统计意义。

![配图 13：手绘形态与相似股票](images/13-pattern-search.png)
*手绘或载入个股形态 → 本地指纹库检索 → 相似股票列表 + 曲线对比 + 历史后验回测。*

### 10. 自选与提醒 · 研究之后，持续跟踪

自选页支持添加、删除、置顶和刷新行情。股票可以从底部热点条、榜单、K 线和个股弹窗中的星标按钮一键加入。

提醒功能按固定周期扫描自选股，检查：价格突破、涨跌幅阈值、盘口异动、量化活跃度变化、以及其他可用信号。

| --- | --- |

| 🔔 系统 | 机会挖掘完成、收盘复盘、模拟跟单等事件通知 |

热点条支持暂停、隐藏和重新打开。

*自选列表、提醒扫描结果和底部实时热点条，把研究延伸到持续跟踪。*

### 11. 模拟盘 · 用本地台账验证策略

模拟盘默认以**本地账户台账**运行，不连接真实资金。撮合使用日 K 近似（非分时盘口），费用进入成本计算。

功能清单：
- 现价买入 / 次日开盘价买入 / 指定价格买入
- 导入历史买入（直接生成持仓和流水）
- 待撮合委托 + 撤单
- 持仓盯市 + 成交流水 + 操作日志
- 权益曲线、收益统计、胜率分析
- 当日结算与复盘
- 重置账户和初始资金

后台配置中还有一项**"模拟盘自动跟单（仅写本地模拟台账）"**：机会报告生成后，达到最低评分档位的股票可按次日开盘价自动建立模拟持仓，持有 N 个交易日后自动挂次日开盘卖单。同一报告中的同一股票不会重复下单。

> 这项功能只写模拟台账，不触碰真实账户。

![配图 15：模拟盘账户、持仓与复盘](images/15-paper-trading.png)
*模拟盘用于验证买入方式、持有周期和风控策略，不连接真实资金。截图需确保出现"模拟盘"字样。*

## 三、贯穿所有页面的 10 项桌面能力

### 1. 全局任务队列

机会挖掘和批量分析不会阻塞页面。每个后台任务拥有唯一 ID、状态、创建时间、实时日志和结果链接。应用重启后，未完成任务被标记为中断——不会把旧任务误判为仍在运行。顶部任务状态和右侧任务抽屉在所有页面可用。

### 2. 全局报告抽屉

报告库是全局入口。任何页面都可以打开报告抽屉，查看最新报告、类型、更新时间和大小，并在应用内预览 Markdown、HTML 等结果。

### 3. 大图 K 线与自动标注

K 线支持 60、120、240、500 或全部数据范围，叠加均线、成交量、局部支撑压力、趋势线和强势形态标注。大图 K 线右侧同步显示股票分析摘要，并提供机会挖掘、个股分析和打开外部交易软件的操作入口。

### 4. 外部交易软件联动

提供交易客户端适配层，根据股票代码和市场打开配置好的外部交易软件。桌面 WebView 中无法正常打开的新窗口，由 Tauri 或本地后端转交系统默认浏览器。Lumo Trade 不读取真实券商账户、不向券商提交委托，也不代替用户确认交易。

### 5. 系统托盘与行情弹窗

关闭主窗口时默认**隐藏而非退出**，后台服务和行情监控继续运行。只有选择"退出 Lumo Trade"时，后端进程才会停止。托盘左键展开 360×520 的行情弹窗，提供自选、热点、板块、异动、快讯和快捷入口；右键菜单可打开控制台、刷新行情或退出应用。

![配图 19：系统托盘行情台](images/19-tray-popup.png)
*关闭主窗口后，Lumo Trade 仍可通过系统托盘持续提供行情和通知。*

### 6. 实时通知与系统事件

桌面端通过 Tauri 原生通知和底部热点条同步推送系统事件：机会挖掘完成、收盘复盘完成、模拟盘自动跟单完成、数据源异常等。通知类别可配置，不同打扰程度分开控制。

### 7. 自动收盘维护

收盘后，系统自动执行：形态指纹库刷新检查、量化雷达当日榜单保存、模拟盘结算与复盘。不需要手动触发，也不依赖应用前台运行——只要后端进程活着，这些任务就会在后台静默完成。

### 8. 数据备份与迁移

支持一键导出整库 SQLite 快照，或导入数据库替换当前数据。导入前自动备份当前数据库，并从旧版本 Schema 迁移到当前版本。备份文件存放在用户数据目录下，不散落到安装目录或临时文件夹。

### 9. 设备授权

打包版默认启用设备绑定授权。设备指纹生成后，授权码在本地验证，激活记录写入 SQLite 的 KV 缓存。源码开发模式可通过环境变量控制是否启用门禁。授权只负责功能门禁，不改变数据分析结论。

### 10. 本地优先的数据策略

用户数据、数据库、报告、模型缓存和配置都在应用用户目录下：

- **只在本地沉淀**：自选、模拟台账、任务状态、报告文件、数据库备份和大部分应用配置
- **外部数据请求**：行情、资金、新闻、财务和期货功能向相应数据源发送股票代码、日期、分页等查询参数
- **可选云端大模型请求**：仅用户启用 Provider 后发起，提示词可能包含股票代码和公开市场数据
- **密钥与截图**：API Key 和 Token 由用户配置，不应出现在截图、报告分享或发布文章中

## 四、技术架构概要

> 这一节为关心技术实现的读者准备。如果只关心功能和使用，可以跳到这里直接看第五节的工作流。

Lumo Trade 的技术栈做了一件简单的事：**让每一层承担适合自己的职责**。

```
┌──────────────────────────────────────┐
│           Tauri 2 (Rust)             │  ← 桌面壳：窗口、托盘、通知、外部链接
├──────────────────────────────────────┤
│   Jinja2 模板 + 原生 JS + Plotly     │  ← 前端：服务端渲染，无重型框架
├──────────────────────────────────────┤
│       Robyn (Python, 8 Workers)      │  ← 本地 API：117 个路由，按业务域编排
├──────────────────────────────────────┤
│  规则引擎 + 30 量化模型 + Kronos AI  │  ← 分析层：规则、模型、LLM 三层并存
├──────────────────────────────────────┤
│          SQLite (WAL 模式)            │  ← 数据层：本地持久化中心，多域统一存储
├──────────────────────────────────────┤
│  TuShare / AKShare / 东财 / 新浪 …   │  ← 数据源：多源获取，明确降级路径
└──────────────────────────────────────┘
```

**分析层**的三个组成部分各司其职：
- **规则与评分引擎**：可解释的机会评分、风险因子、技术形态和资金信号
- **30 个量化模型**：投票和热度统计，用于选股、机会分析和个股量化矩阵
- **Kronos 金融基础模型**：K 线序列建模与预测，支持 CPU / CUDA / Apple MPS
- **大语言模型**：个股解读、报告和评审团覆盖层，Provider 和 Key 由用户配置

这种分层设计避开了两个极端：所有输出来自不可解释的黑盒，或者模型不可用就导致产品瘫痪。

**数据源**的降级策略也很明确：每个功能都预设了主源 → 备源 → 本地缓存的回退路径。系统不假设任何接口永远稳定，而是保存历史快照和来源状态，在实时源失败时明确告诉用户"数据不可用、已回退或仍在使用历史数据"。

## 五、一套实际可执行的工作流

### 🌅 盘前

1. 打开**股指期货**，查看 IF/IH/IC/IM 基差、席位多空和近几日持仓趋势变化。
2. 打开**资金榜单**，查看最近 5 日和 30 日资金主线——哪些行业在持续吸金。
3. 在**风险·机遇**页面确认市场风险指数和已有持仓风险——今天适合进攻还是防守。
4. 用**条件选股**组合资金、技术形态和量化信号，产出一份盘前观察池。

### 🔴 盘中

1. 用**大盘云图**观察热点是扩散还是收缩——扩散意味着情绪健康，收缩意味着资金在避险。
2. 用实时异动和**量化雷达**发现拉抬、砸盘、活跃板块和异常股票。
3. 从热力图或榜单点开**个股工作台**，检查量价、筹码、资金流向和风控页签。
4. 把需要持续跟踪的股票加入**自选**；有必要时在**模拟盘**记录操作计划。

### 🌙 盘后

1. 启动**机会挖掘**或指定股票池的批量分析。
2. 在**挖掘引擎**页面观察阶段进度、失败项和异常日志。
3. 通过**机会画布**从板块和资金维度审阅当日的股票-板块关系。
4. 对重点标的：翻财务三大表、机构持仓变化、关联热点和形态回测。
5. 运行**模拟盘结算**和当日复盘——胜率、盈亏比、最大回撤一目了然。
6. 在**报告与健康**页检查新生成报告、数据源状态和评分健康度。
7. 如有自动跟单，确认模拟台账中的新持仓和结算结果。

## 六、系统边界：它不会替用户做什么

Lumo Trade 是数据和研究工具，不是持牌证券投资咨询服务。明确几条边界：

- 📊 评分、回测、形态相似度和 AI 解读 **不代表未来收益**
- 🔍 吸筹、主力、控盘、情绪和风险等指标来自公开数据和算法代理，**不是对真实交易主体意图的确定识别**
- 📝 模拟盘使用日 K 近似撮合，**不能复现真实分时流动性、滑点和冲击成本**
- ⚠️ 数据源可能延迟、缺失或改变接口——请留意页面中的数据时间戳和来源标注
- 🤖 大语言模型可能产生错误解释——最终结论应回到原始数据和可解释规则
- 📜 用户应自行遵守数据提供方条款和所在地区的法律法规

## 结语

如果只看某一个页面，Lumo Trade 很容易被理解成"又一个行情终端"或"又一个 AI 选股工具"。

但把 15 个桌面页面、21 个页签的股票工作台、10 项全局能力和一套完整工作流串起来后，它真正形成的是一条**本地优先的投研流水线**：

**从全市场观察出发 → 经过资金、量化、事件和形态筛选 → 进入个股多维研究 → 再通过风险撮合、模拟执行、提醒、任务和报告完成闭环。**

它的价值不在于给出一个神秘答案，而在于把信息来源、分析过程、风险因素和历史结果放在同一张桌面上——让研究更连续、更可解释，也更容易复盘。
