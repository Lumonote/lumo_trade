## 通用拍摄规范

- 建议主窗口尺寸：1440×920 或 1600×1000。
- 建议导出 PNG；公众号正文图优先使用 3:2、16:10 或接近横向桌面比例。
- 首次启动先点击“我已知晓风险”，避免风险弹窗遮挡正文截图。
- 截图前等待页面数据加载完成，避免保留“读取中”“加载中”或布局跳动状态。
- A 股颜色口径为红涨绿跌，不要在后期调色时反转颜色语义。
- 不要拍入 API Key、TuShare Token、设备 ID、授权码、真实券商账号、个人路径、私有报告内容和完整错误日志。
- 个股示例优先选择数据完整、无敏感持仓含义的公开股票；图注应避免写成荐股语气。
- 涉及模拟盘时，确保画面明确出现“模拟盘”或“仅模拟”字样。
- 风险·机遇页面如出现指令化算法标签，不要让具体股票名称、代码或个人持仓与这些标签同屏；优先裁切为不含个股身份的结构示意。
- 配图 04、08、11、18 信息密度较高，优先拍主画面后再做局部裁切或组图，不要为了保留整屏而把文字缩到手机端无法辨认。
- 如页面数据源暂不可用，可换交易时段重拍；不要用开发者工具伪造数据。
