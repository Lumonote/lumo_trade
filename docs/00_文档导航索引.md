## 📖 阅读建议

### 新手入门

建议按以下顺序阅读:

1. **文档03** - 系统架构技术文档
   - 先了解项目整体结构
   - 掌握基本参数配置

2. **文档01** - 投资机会挖掘系统
   - 理解核心功能和使用方法
   - 学习量化模型和筛选策略

3. **文档02** - 数据采集爬虫系统
   - 配置数据源
   - 解决数据采集问题

### 问题排查

遇到问题时:

1. 先查看本索引的"快速查找"部分,定位相关文档和章节
2. 在对应文档中搜索关键词(Ctrl/Cmd + F)
3. 参考相关章节的解决方案和代码示例
4. 如果问题未解决,查看相关的优化总结文档

### 深度学习

想深入了解某个模块:

1. 阅读该模块的"完整优化总结"章节
2. 按阶段顺序了解功能演进
3. 研究代码实现和优化思路
4. 参考使用示例和最佳实践
