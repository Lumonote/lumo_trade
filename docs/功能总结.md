## 📌 一、引言：当AI遇见量化投资

在瞬息万变的金融市场中，投资决策的复杂程度远超想象：

- ⏰ **时效性**：市场机会稍纵即逝，如何快速捕捉？

传统的股票分析方法往往局限于单一视角，难以全面把握投资机会。而**Kronos智能投资决策系统**，正是为解决这些痛点而生。

## 🌟 二、技术核心：金融时序基础模型TSFM

### 2.1 从语言模型到时序模型

近年来，以ChatGPT为代表的大规模语言模型（LLM）在自然语言处理领域取得了革命性突破。这一成功启发了研究者：**能否将类似的技术应用于时间序列预测？**

**时序基础模型（TSFM）**应运而生。其核心理念是：
- ✨ 在海量时序数据上进行**预训练**
- 🎯 构建一个**通用的、与任务无关**的模型
- 🚀 支持**零样本学习**，无需额外训练即可应用到新任务

这种能力在金融领域尤为重要。想象一下：
- 当一只新股上市，历史数据稀缺时
- 当市场环境突然变化，传统模型失效时
- TSFM能够凭借其在大量数据上学到的"市场规律"，快速适应新情况

### 2.2 Kronos：专为金融K线打造

然而，金融时序数据有其独特性：
- 📉 **低信噪比**：市场充满随机波动和噪声
- 🌊 **强非平稳性**：趋势、周期性随时可能改变
- 🔄 **复杂依赖**：价格、成交量、市场情绪相互影响

通用的TSFM在面对金融数据时，往往"水土不服"。

**清华大学团队**开发的**Kronos模型**，正是为解决这一"领域错位"问题：
- 🎯 **垂直领域专注**：只针对金融K线数据优化
- 🏗️ **两阶段架构**：K线分词 + 自回归预训练
- 📈 **可扩展设计**：从4.1M到499M参数，灵活适配不同场景

## 🏗️ 三、Kronos架构解析

### 3.1 两阶段框架

Kronos的创新在于将连续的K线数据转化为"语言"：

```
阶段一：K线分词（K-line Tokenization）
┌──────────────────────────────────────┐
│  连续数据 → 离散令牌                  │
│  (OHLCV数据) → (层级化Token序列)      │
│  技术：Binary Spherical Quantization │
└──────────────────────────────────────┘
                    ↓
阶段二：自回归预训练（Autoregressive Pre-training）
┌──────────────────────────────────────┐
│  学习"语法" → 预测未来                │
│  GPT-2架构 → 由粗到精预测Token        │
│  能力：捕捉市场长期和短期规律         │
└──────────────────────────────────────┘
```

#### 为什么要"分词"？

传统方法直接预测价格，面临两大难题：
1. **数值空间连续**：价格可以是任何数值，预测难度大
2. **缺乏语义信息**：模型难以理解价格变化背后的"含义"

Kronos的分词策略，就像把股价走势翻译成"市场语言"：
- 📗 **绿色令牌**：小幅下跌
- 📕 **红色令牌**：大幅上涨
- 📘 **蓝色令牌**：震荡整理

模型学习这些"词汇"之间的规律，就能预测未来的"语句"。

- ✅ 入选股票质量极高
- ✅ 多维度信号强烈一致
- ✅ 风险相对较低
- ⚠️ 筛选出的股票数量较少（5-10只）
- ⚠️ 可能错过部分潜力股

**适用场景**：
- 熊市或震荡市
- 账户资金量大
- 追求稳健收益

#### ⚖️ 平衡模式（Balanced）- 默认推荐

**适合人群**：大多数投资者

**筛选标准**：
```
阶段1：买入信号≥2个 或 买入比例≥20%
阶段2：RSI<75 且 (MACD金叉 或 布林带突破)
阶段3：股民情绪≥50 且 板块情绪≥45
阶段4：PE<60 且 营收或利润有增长
阶段5：利好≥利空（允许持平）
```

**特点**：
- ✅ 质量与数量兼顾
- ✅ 适应多数市场环境
- ✅ 操作空间较大
- ✅ 筛选结果10-15只
- 📊 质量与覆盖面平衡

**适用场景**：
- 所有市场环境
- 建立股票池
- 分散投资

#### 🚀 激进模式（Aggressive）

**适合人群**：激进型投资者、短线交易者

**筛选标准**：
```
阶段1：买入信号≥1个 或 买入比例≥10%
阶段2：RSI<85 (允许部分超买)
阶段3：股民情绪≥40 或 板块情绪≥35
阶段4：PE<80 (允许高估值成长股)
阶段5：不考虑事件面
```

**特点**：
- ✅ 捕捉更多潜在机会
- ✅ 包含高风险高收益标的
- ✅ 筛选结果15-25只
- ⚠️ 单个标的风险较高
- ⚠️ 需要更强的风控能力

**适用场景**：
- 牛市或强势市场
- 追求高收益
- 短线操作

### 8.3 参数调整

#### 预测参数（用于单股分析）

```bash
python examples/prediction_batch_example.py \
    --stock-code 600519 \
    --temperature 0.8 \        # 采样温度（0.5-1.5）
    --top-p 0.90 \            # 核采样阈值（0.8-0.95）
    --sample-count 3           # 采样次数（1-5）
```

**参数说明**：
- **Temperature（温度）**
  - 保守：0.5-0.7（适合趋势明确的市场）
  - 平衡：0.8-1.0（适合一般市场）
  - 激进：>1.0（适合高波动市场）

- **Top-p（核采样）**
  - 推荐范围：0.8-0.95
  - 平衡预测的多样性和稳定性

- **Sample Count（采样次数）**
  - 1次：最快，但可能不稳定
  - 3次：平衡速度和稳定性（推荐）
  - 5次：最稳定，但耗时较长

### 10.2 系统局限性

#### ⚠️ 数据依赖

```
依赖外部数据源：
  - API可能限流或失效
  - 数据更新可能延迟
  - 历史数据可能有误

应对措施：
  - 多数据源备份
  - 缓存机制
  - 数据校验
```

#### ⚠️ 模型局限

```
预测不是100%准确：
  - 黑天鹅事件难以预测
  - 政策变化影响大
  - 市场情绪难以量化

合理预期：
  - 提供决策参考，非绝对答案
  - 中长期趋势把握较好
  - 短期波动难以精确预测
```

#### ⚠️ 计算资源

```
资源消耗：
  - CPU：中等（并发分析时较高）
  - 内存：2-4GB（取决于并发数）
  - 存储：模型文件约500MB-2GB

建议配置：
  - CPU：4核以上
  - 内存：8GB以上
  - 硬盘：10GB可用空间
```
