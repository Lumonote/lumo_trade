# 智能环境检测使用说明

## 快速开始

```bash
# 1. 检测所有可用的Python环境
python tools/smart_env_detector.py

# 2. 查看检测结果
# 脚本会自动列出所有环境并推荐最合适的
```

## 功能特点

### 自动检测多种Python环境

1. **Kronos专用虚拟环境** (最高优先级,评分1000+)
   - Windows: `%LocalAppData%\Kronos\venv`
   - macOS/Linux: `~/Library/Application Support/Kronos/venv` 或 `~/.kronos/venv`

2. **当前激活的虚拟环境** (评分900+)
   - 通过`VIRTUAL_ENV`环境变量检测

3. **项目虚拟环境** (评分800+)
   - `venv/`, `.venv/`, `env/`, `.env/`, `virtualenv/`

4. **pyenv环境** (评分700+,仅macOS/Linux)

5. **Conda环境** (评分500+)
   - 检测所有conda环境

6. **系统Python** (评分300+)
   - PATH中的Python

### 智能评分系统

基础评分 + 依赖加分:
- 有PyTorch: +100分
- 有Pandas: +50分
- 有NumPy: +30分
- Python 3.11: +50分
- Python 3.12: +40分

### 环境缓存

检测结果会缓存到 `~/.kronos/env_cache.json`,加快后续检测速度。

## 集成到现有代码

### 方式1: 使用python_detector.py (推荐)

```python
from tools.python_detector import get_python_command

# 自动使用智能检测
python_cmd = get_python_command(use_smart_detection=True)

# 或禁用智能检测,使用传统逻辑
python_cmd = get_python_command(use_smart_detection=False)
```

### 方式2: 直接使用smart_env_detector

```python
from tools.smart_env_detector import SmartEnvDetector

detector = SmartEnvDetector()
detector.detect_all_environments()

# 获取最佳环境
best_env = detector.get_best_environment()
if best_env:
    print(f"使用: {best_env.path}")

# 打印所有环境
detector.print_all_environments()
```

## 在PowerShell脚本中使用

修改 `quick_start.ps1` 中的 `Get-PythonCommand` 函数:

```powershell
function Get-PythonCommand {
    # 尝试使用智能检测
    try {
        $detectScript = Join-Path $scriptDir 'tools\smart_env_detector.py'
        if (Test-Path $detectScript) {
            $bestPython = python $detectScript 2>$null
            if ($LASTEXITCODE -eq 0 -and $bestPython) {
                Write-Host "智能检测: $bestPython" -ForegroundColor Green
                return $bestPython
            }
        }
    } catch {}

    # 回退到原有逻辑
    # ...
}
```

## 常见问题

### Q: 检测很慢怎么办?

A: 第一次检测会比较慢(需要检查所有环境的依赖),但结果会缓存。后续使用缓存会很快。

### Q: 如何强制重新检测?

A: 删除缓存文件 `~/.kronos/env_cache.json` 后重新运行。

### Q: 评分规则合理吗?

A: 评分规则可以根据需要调整。编辑 `smart_env_detector.py` 中的 `_deduplicate_and_score()` 方法。

### Q: 能检测Docker容器中的Python吗?

A: 当前版本主要针对本机环境。容器内的Python会被检测为系统Python。
