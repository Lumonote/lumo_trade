# Kronos 授权管理工具

## 授权码生成工具

### 使用方法

#### 方式1：交互式使用

```bash
python license_admin/generate_license.py
```

然后根据提示输入用户的设备ID。

#### 方式2：命令行参数

```bash
python license_admin/generate_license.py <DEVICE_ID>
```

例如：

```bash
python license_admin/generate_license.py 940D3210E6D5CCD1
```

### 工作流程

1. **用户获取设备ID**
    - 用户启动 Kronos 应用
    - 在授权激活界面可以看到设备ID
    - 用户可以点击"📋 复制"按钮复制设备ID

2. **管理员生成授权码**
    - 使用本工具输入用户的设备ID
    - 工具会生成对应的授权码
    - 授权码格式: `KRONOS-XXXXX-XXXXX-XXXXX-XXXXX`

3. **用户激活**
    - 用户在激活界面输入授权码
    - 系统验证授权码是否与设备ID匹配
    - 验证通过后，授权信息会保存到本地

### 授权验证机制

- 授权码使用 SHA-256 算法基于设备ID生成
- 每个授权码只对特定的设备ID有效
- 授权码格式验证确保输入正确
- 设备硬件变更后需要重新激活


## 安全说明

- 设备ID基于硬件信息生成，具有唯一性
- 授权码使用加盐哈希算法，无法反向推导设备ID
- 授权信息本地存储在用户目录 `~/.kronos/.license_cache`
- 建议定期更换盐值以提高安全性

## 注意事项

1. 设备ID为16位十六进制字符
2. 授权码区分大小写（建议统一使用大写）
3. 用户更换硬件后需要重新获取授权码
4. 本工具仅供管理员使用，请勿分发给普通用户
